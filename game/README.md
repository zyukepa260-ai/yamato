# 法廷の選択（民法・民事訴訟法 法廷シミュレーション）

有名判例をもとにした民事事件で、新人弁護士として手続と主張を選んでいくブラウザゲームです。
`index.html` をブラウザで開けば遊べます（ビルド不要・外部依存はGoogle Fontsのみ）。

| 章 | 事件 | 題材となる判例・論点 |
|---|---|---|
| 第一章 八百屋の看板 | 東京地裁・建物明渡請求（被告代理人） | 信頼関係破壊法理（最判昭28.9.25）、特段の事情の立証責任（最判昭41.1.27）、答弁書と擬制自白、和解の特別授権、時機に後れた攻撃防御方法 |
| 第二章 登記簿の向こう側 | 横浜地裁（合議）・所有権移転登記手続請求（被告代理人） | 94条2項・110条類推（最判平18.2.23）、訴訟告知、自白の撤回、尋問の制限、続審制 |
| 第三章 先に登記した男 | さいたま地裁・所有権移転登記手続請求（原告代理人） | 背信的悪意者（最判昭43.8.2）、転得者（最判平8.10.29）、処分禁止の仮処分、管轄、判決による登記 |

登場人物・事件は架空で、事案は学習用に単純化しています。
